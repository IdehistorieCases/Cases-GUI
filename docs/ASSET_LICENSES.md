# Versailles room asset review and licenses

Reviewed in an isolated Godot 4.7.2 GL Compatibility project at `assets/versailles/project.godot`. Raw downloads are in `assets/versailles/source/`; selected runtime copies live in `godot/assets/versailles/optimized/`. This separation keeps rejected comparison assets out of the game project. The rendered comparison is `assets/versailles/review/previews/versailles_asset_review.png`.

| Furniture Kit (Kenney) | Rejected for this room; samples retained for review | The official CC0 pack was downloaded. Eight representative GLB models imported successfully. Its modern stylized low-poly furniture is visually inconsistent with the realistic selected furniture. Full pack: 140 models. |
| 3D Flag Pack (Omie's Assets) | Rejected / download blocked | The official listing describes current national flag meshes; those do not verify 1919 flag designs. The official page was rate-limited when obtaining the download, so no file was copied or used. |

| 1800s Book Stands (Sketchfab) | Blocked | The Sketchfab listing identifies CC BY 4.0 and the title suggests the period may fit, but no file was available via the official download route here. |
| Quill, Parchment & Inkwell (Sketchfab) | Blocked | The Sketchfab listing identifies CC BY 4.0, but no file was available via the official download route here. The red quill would need a visual treatment decision before use. |
| Victorian Typewriter (Sketchfab) | Blocked / not selected | The Sketchfab listing identifies CC BY 4.0, but no file was available via the official route here. Its creator describes it as a fictional design, not a historical recreation; it is not used to claim 1919 accuracy. |

The review scene imports all accessible Poly Haven candidates, eight Kenney samples, and seven Quaternius samples in a common neutral gallery. Sketchfab assets and the flag pack are shown as blocked/rejected cards because no source model was downloaded. The imported model dimensions, mesh-node counts, material surface counts, triangle counts, and texture sizes are printed as `ASSET_METRIC` lines when the review project runs. Meshes loaded in the current Compatibility renderer; the asset gallery was rendered and visually inspected. This review does not verify a web export.

All Poly Haven candidates imported with UVs and normals on every reviewed surface. Their models and swatches use 2K textures. The table and drawer pivots are at floor level, the chair pivots are near the floor, and the chandelier pivot is at its hanging point. The chandelier has one transparent surface; the high-poly cabinet has three. The Quaternius FBX samples load, but their surfaces report missing UVs (one or two surfaces per model) and the furniture proportions in the sample set vary widely. Kenney sample geometry imports with UVs and normals, but has no image textures and uses a visibly stylized low-poly look. These observations informed the style and runtime decisions above.

The room shell and simplified pleated drape panels are custom in-house box geometry because the reviewed architecture and curtain candidates were unavailable or unsuitable. The carpet, procedural landscapes, frames, sconces, palms, and sideboard props are also authored in Godot from primitives and generated textures. The drapes are a visual placeholder, not a cloth simulation or a detailed curtain asset. The imported 2K source bundles remain unchanged. For the five selected runtime bundles, 19 source JPEG maps were resized to 1K progressive JPEG copies at quality 88; the selected runtime folders decreased from 29,083,922 bytes to 5,355,802 bytes. The table, chandelier, and drawer retain their source model data, while their referenced runtime maps use the optimized copies.
